## 如何理解“变动参数”

规程第五节先给出本次平台的开关、限制与不变参数，再说明“对于变动参数，通过下面案例，分岗位任务进行说明”。因此不能直接套用案例参数，也不能把后续操作机制全部排除。

| 层次 | 原文内容 | 智能体如何使用 |
| --- | --- | --- |
| 本次平台设置 | 关闭数智化建设、碳达峰/碳中和；不考财务报表；现金断流或终局权益≤0破产 | 适用该规程时约束经营路线。费用菜单中的碳项目不构成重新启用依据；不考报表仍要管理资金与权益 |
| 平台限制 | 一次广告窗口；每单申报≤30%；未收货原材料价值+本次下单价值≤总资产 | 读取当前正式依据，关联竞单、采购与现金规划。采购解释另有冲突，见下文 |
| 不变参数表 | 贷款合计上年权益3倍，最长长贷2年；库存折价80%；原料/成品紧急倍率2/4；税率25%；商誉100；报价下限90%；产线上限16；违约40% | 属于该规程的平台参数，不能当普通示例删掉；具体赛题或正式补充明确覆盖时采用覆盖。没有进入冻结来源时保留适用情景与限制，不生成假的正式引用 |
| 案例背景和参数 | HQ公司的摩托业务、现金400000、月管理费5000、员工工资、产品/BOM、融资套餐、材料交期、市场/认证周期等 | 当前题目没有明确采用该案例时，从当前题目分别查询；不能将案例整套注入当前企业 |
| 案例讲解的操作机制 | 报价影响分单、offer影响入职、季度发薪、安装/培训完成时点、设计收费、应收应付起点等 | 保留机制，代入当前题目参数；同一机制中有算例错误时，保留明确部分并定位争议 |
| 页面示范状态 | 在职员工名单、已安装且停产的传统线、市场材料数量、示范订单与应付账款 | 说明页面字段含义，不自动成为当前企业的初始人员、设备、库存、合同或欠款 |

## 按岗位落实的机制

| 岗位/环节 | 机制与时点 | 规划中的对应要求 |
| --- | --- | --- |
| 财务融资 | 不同融资组合共同占用额度；申请在正常经营阶段；借款期+贷款期限到期。方式1到期还本付息，方式2每季付息；系统提供每季到期账单 | 来源中明确权益基数、已有债务、套餐金额与利率口径，安排本金及利息。初始现金不能无依据替代首年贷款权益基数 |
| 应收/贴现 | 交货形成应收，交货期+账期收款；贴现扣除贴息后到账，贴息属财务费用 | 不能申报即收款、不能把应收全额当现金；贴现后不能又在原到期日重复收款 |
| 应付/原料 | 下单无付款且不可撤销，下单期+送货期收货；收货形成应付，收货期+账期付款。到期不主动收货会自动收货并损失商誉 | 分开下单、收货、付款；材料表账期0就在收货当季付款，不能套通用解释中的“1季”。无现金付款不等于无采购额度或部门预算要求 |
| 费用/报表 | 月管理费×3手动支付；本金、利息手动支付；维修、税费自动；折旧非现金。提交后可以查看财务信息 | 自动费用仍须预留现金且不重复支付；不把“无报表考核”当无须查账或可以不还债 |
| 预算 | 营销、生产设计、人力三个部门同时填报确认；基线不可修改；使用率<80%或>120%扣分；追加由系统计算并经财务审批 | 不把预算划拨重复计作经营付款，不事后改基线消除偏差；80%/120%边界不属于超限，零预算和计扣频次尚需明确依据 |
| 人员招聘 | 人才市场没有企业间工资竞争；offer/期望月薪<70%不入职，70%至不足100%随机，≥100%入职；次季查看结果；修改以最后工资为准 | 给出拟招人数、等级、效率要求和offer；不能为抢人无依据加价，也不能把市场人员当成已雇人员 |
| 发薪/解聘 | 当季月薪×3；仅空闲可解聘，另付赔偿及欠薪；欠薪跨季强扣且效率减半，连续两季欠薪会离职、赔偿、扣商誉 | 空闲与培训仍须计薪，工作/培训状态限制操作；不将欠薪用作低成本融资 |
| 培训/激励 | 培训按人数付费，开始期+培训周期后可配置；培训改变岗位/工资但不提高效率，高级不能再培训。一次性激励不改工资；涨薪当季旧工资、次季新工资 | 区分一次性现金、未来经常性工资和效率。涨薪算例有算术错误，不因此丢弃清楚的生效时点 |
| 生产线 | 一次性购买付款，开始期+安装周期可用；停产状态才可配置/转产，生产周期按每批计算 | 安装中的产线不能开产，同一工人和产线不能重复占用。实际产量按实际人员效率求和及班次规则调用工具，不直接使用基础产量 |
| 产品图纸/设计 | 产品×特性搭配形成图纸版本；每次设计重新收费，即使以前设计过 | 图纸设计费与产品资格研发、特性升级分列，不能只预算一次终身设计费 |
| 特性研发 | 目标≥当前值；(目标−当前)×单位研发费；点击研发立即扣现金 | 用 `feature_research(current_value,target_value,unit_cost)`，不按目标总值收费，后续升级沿用前次目标及执行条件；目标需核对当前特性上限，不擅自套用产品资格提前期 |
| 开产成本 | 开产需产品生产资格、图纸/BOM、原料、停产线、配置人员及现金。计件工资开产即付；在制品成本含材料、月薪×生产月数、计件工资 | 另有明确开产费时按当前赛题计入。成本归集与现金付款不能重复扣款，生产季数需显式转月数 |
| 设备后续费用 | 维修例在进入建成周年季度扣现金；折旧例在周年季度结束转换计提，四年直线法、净值止于残值；拆除只收残值 | 维修和折旧保留各自时点，不能混成一个周年现金事件。设备净值不等于拆除现金 |
| 市场/产品/ISO | 开拓/资格投入一次性扣款，不可中断加速，投入期+周期自动取得；入围需订单市场与ISO，产品生产资格只要求开产前具备 | 不能要求先拿产品资格才能竞单，也不能未完成市场/ISO就承诺入围 |
| 广告/申报 | 按市场、限时一次投放，只作用本次竞单，随后归零。同单申报以最新一次为准，数量0取消 | 多岗位申报不相加；报价须在参考价90%至100%，每单量≤floor(30%×该单量) |
| 分单 | 按竞单指数排名，依次分配申报量或剩余量。同分组最小申报量M，剩余A≥N×M时每队M，否则每队floor(A/N) | 未解释的余量分配不猜；指数不是中标概率，缺少对手状态不能保证拿足。市场份额不含网络营销销量 |
| 交货 | 只有实际分配订单才是合同；截止季包含当季，必须产品/特性匹配且一次足量；违约后不能再交货 | 分开申报、分配、交付、应收、收款。未分配量属于情景，不预先充作收入；违约需计费用和商誉影响 |

## 原文不一致与明确覆盖

以下不能统一当作“规则缺失”，也不能全部自行裁决：

- 明确覆盖：本次平台明确关闭碳，后面通用费用列表提到碳不能覆盖该开关；应付解释明确“1季（以规则为主）”，因此当前材料表0账期不是与它同等的冲突。
- 真正冲突：不变参数及费用表违约比例40%，费用解释20%；班次表12时制1.2倍，解释称产量加倍；涨薪文字说新工资=旧工资+涨薪金额，算例10000+1300却写2600；采购上限的对象“未收货/未付款”和比较“≤/<”均不同。定位两边依据，采用已核对口径，未解决保留明确情景和影响。
- 不同事件：维修的周年进入时点与折旧的周年结束时点属于两个事件，不是必须合并的矛盾。
- 未明确：方式2贷款条款“到期时支付本年和当季度的利息”疑有错字，利率周期、分期算法不能凭该句推导；所得税包含弥补以前亏损条件，不能由单季收入推税；完整最终评分、同分尾差、零预算处理也不能补造。

## 用例如何验证

算例数值仅存在于文档和测试情景，不写入题目、初始资产或运行预设。分职责提示词只携带对应机制及必要平台边界；路线节点负责共享资源、工资生效、图纸/特性、付款责任和末期义务交接，分段不会重复接收全部岗位讲解。输出阶段仍只消费生成时冻结的结构化行动与预算准备结果。差额工具不维护特性状态、自动判定上限或跨期进度，这些仍需规划时依据当前规则核对。上述验证没有模拟其他队伍、税务或完整平台状态转移，不能作为真实模型质量或经营可行性证明。
